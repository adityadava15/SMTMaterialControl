Material Input via QR Scan

Pindai barcode atau QR code roll komponen SMT untuk registrasi stok masuk secara instan.

Tips: Isi jumlah roll dulu (jika > 1) sebelum scan QR. Hanya Superadmin yang dapat mengubah jumlah roll.

Sesi Input Saat Ini

Material ID RID Qty Masuk Waktu
Belum ada data input di sesi ini

Panduan Penggunaan

  • Fokuskan kursor di kolom "Scan QR Code Material"
  • Scan QR code komponen menggunakan scanner barcode fisik atau kamera
  • Spesifikasi material diambil otomatis dari master data
  • Material ID, RID, dan Quantity akan otomatis terurai dan terisi
  • Klik "Input Material" untuk menyimpan transaksi ke sistem inventori

QR Code Tidak Dikenali

Format kode QR tidak sesuai pola roll komponen SMT. Silakan periksa kembali atau gunakan form input manual.
