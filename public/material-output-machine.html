Panduan Koneksi Direktori Log Mesin Samsung & Hanwha

Sistem ini dirancang khusus untuk lini SMT dengan 4 Mesin Samsung dan 1 Mesin Hanwha:

  • Deteksi Otomatis Type Meter dari Nama File:
    Sistem membaca kode produk dari nama file:
    • H_HXE12FR-A1-...log → Otomatis dialokasikan ke HXE12FR
    • H_HXE128-KP-V3-...log → Otomatis dialokasikan ke HXE128-KP
    • H_HXE310-KP-V3-...log → Otomatis dialokasikan ke HXE310-KP
    • H_HXE310-V2-...log → Otomatis dialokasikan ke HXE310
  • Ekstraksi Baris [Tape Feeder]:
    Sistem otomatis mengekstrak kolom ke-3 (Material ID / Part Number) dan kolom ke-6 (Mounted Count / Pcs yang terpasang pada PCB).
  • Koneksi Jaringan LAN:
    Jika folder berada di PC mesin Samsung / Hanwha yang berbeda, cukup jadikan folder Pd Info sebagai Windows Shared Folder (misal: \\IP_PC_MESIN\Pd Info) atau Map Network Drive (misal: Z:\Pd Info). Masukkan path tersebut pada kotak input di atas dan klik Simpan Path.
